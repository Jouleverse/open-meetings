#### 二、区块链的合规边界：规范永远滞后于创新

**基本判断：合规问题问监管是问不出答案的，答案在市场检验之后。**

- 所有新兴行业都属于创新前沿，天然走在现行法律法规前面；法律法规是滞后的。通常是行业先摸索，监管再跟上，制定适应市场需要的规则。
- 摸索期必然有大量不确定，这要靠先行者探索出来，而不是去问监管部门"这样做行不行、那样做行不行"——答案多半是"不知道"，或者干脆"不行"。

**两个类比：**

1. **网约车**：起步时若去问有关监管部门，很可能会被告知不合法——没有出租车牌照，就是黑车、非法营运；中间还引发传统出租车行业对抗，本质是分蛋糕的利益博弈。但监管最终没有一刀切禁掉，而是专门出台网约车管理办法，把它"从黑变成白"。原因是：出租车解决不了运力不足，网约车确实满足打车需求、体验明显更好，人民群众需要这种服务。
2. **AI 短剧**：个别传统有关产业所在省份的官方媒体率先呼吁严管（粗制滥造、情节猎奇、画质粗糙）。细究背后也是利益之争——AI 短剧冲击传统影视行业，影视基地投资与群众演员面临被淘汰。国家有关监管部门最终做的是导向引导（禁止不良价值观内容，同时鼓励符合主流价值观的发展），而不是一刀切禁止。

**结论**：合规与规范走在行业后面，而且规范本身在变化。规范最终必须符合最广大人民的需求——监管不敢冒天下之大不韪，把人民群众喜闻乐见的东西直接禁掉。

**那为什么区块链在国内监管这么严格？**

- 区块链近 20 年的发展，唯一被证明有较广泛应用的场景就是“炒币”（投资/投机），始终没能在“炒币”之外证明自己的价值。
- 炒币这个赛道是"赢的人少、输的人多"：如果放开，99% 的人是亏钱骂娘的。
- 对比之下，网约车、短剧是让绝大部分用户体验提升、得到实惠，所以能被认可；炒币则是让大部分人体验下降（更快亏光）。
- 所以现在的现状是符合现实的。假如区块链在炒币之外的某个领域（哪怕只有一个领域）真正创造出巨大价值，到了成千上万人每天都离不开的程度，监管同样会像网约车那样事后追加名分、给个说法。
- 简而言之：**还有很长的路要走。**

#### 三、JNS 第二任 CEO 选举停滞与治理规则

##### 1. 停滞的直接原因：投票规则的技术性漏洞

- 第二任 CEO 参选提案煜歌卡在 JNS 代表度未达线。但其支持票所代表的 JNS 数量其实**远高于以往的提案**；之所以仍不达标，是因为 JNS 总量增加很多、分母过大，百分比被稀释。
- 这说明原先设计的投票规则本身有需要优化、甚至需要重新设计的地方。

##### 2. 关于投票权重快照

- 楼兰渔夫提出：投票权重是取投票时点的快照，还是归集域名后动态变化？这属于会彻底改变结果的关键参数，也可能被利用。
- 教链回应：应该是有快照的，但记不清了；要确认的话，可以让 agent 去看 GitHub 上的代码逻辑，一看便知。

##### 3. 核心建议：先解决"人"的问题

- 技术层面的动作——无论是改参数、改治理规则，甚至 JNS 本身升级——都牵一发动全身，要改的地方很多。
- 现在真正的问题是 JNS 群龙无首，没有一个人牵头梳理推进，所以事情一直悬着。
- 既然通过治理程序选人这条路已经卡壳，可以**先跳过现有程序**：举例，由 core 直接招募一位"代理 CEO"（不是经原治理程序正式选举产生），全面负责梳理、推动、盘活 JNS。
- 转正之前，先由 core 资助其工作（计入 PoWh）；等整体梳理清楚、开发做出来之后，再走一次组织程序正式转正。

##### 4. 会上结论与后续程序

- 主持人 Koant 及与会者（微尘、芳芳、楼兰渔夫、Koant）均表示赞同上述"由 core 招募代理 CEO"的思路，形成一致意见。
- 教链建议走一次"粗糙共识"程序：
  - 会后**单独新开一个 issue**（该事项属于治理程序层面，不涉及代码），写入本次会议结论；
  - 今天会上赞同的人到该 issue 下表态赞同，留在 GitHub 上，有据可查；
  - 借助该 issue 发群扩散，扩大共识，并留到下次 CGC 会议再听取更大范围的意见。
- 该 issue 的内容定位（教链原话大意）：鉴于 JNS 迟迟没有一个负责人去推进相关工作、导致停滞，由 core 方面提出方案，招募一位代理 CEO，来全面梳理并重新盘活 JNS。
- 具体 issue 由主持人 Koant 会后创建。
